# Invariant list

/boundaries' code scout and its lock read this list, and /issue-review's S3 checks locked Rules against it. Both write a line the work meets as one Rule in one shape: the line's invariant, the screens it binds, and on a `grep` line every hit as a `path:line` site. `<files>` in a command means the files the work touches. A ticket that adds a line here carries CLAUDE.md critical trigger 2 in its Rules.

Marks: `device` is proven on the emulator, `grep` carries the command that lists its sites, and `test` names the jest suite that computes it.

1. A name is non-blank. `test` · business rule 9 · suites `__tests__/add_account.schema.test.ts`, `__tests__/screens/settings/categories/add_edit_category_schema.test.ts` and `__tests__/commitment_form_shared.test.ts`.
2. A name is unique where a business rule says so, which rule 8 does for accounts. `test` · business rule 8 · suite `__tests__/account_name_taken.test.ts`.
3. At font scale 2.0 after a cold launch, every text node is whole or ends in a whole `…`, and every amount is whole. `device` · `docs/adr/2026-09-27-transactions-search-tally.md` §7, `docs/adr/2026-10-03-android-ellipsis-paint-typeface.md` §6.
4. No text node's box overlaps another's by more than 1 dp. `device` · `.claude/rules/ui.md` § Screen layout.
5. Every pressable's touch area, its box plus its hit slop, is at least 44 dp high. `device` · `docs/design-system.md` § Touch (`TouchSize.min`, `:105`) and convention 4 (`:121`), `touchFloorHitSlop` in `src/constants/theme.ts` (`:299`).
6. A glyph colour clears 3:1 on each fill it draws on, measured on the untinted fill beneath any tint. `test` · `docs/adr/2026-09-26-category-colour-contrast-floor.md` §1 · suite `__tests__/category_colour_contrast.test.ts`.
7. A sheet's consumer closes it through `onOpenChange` and `onCloseComplete` and wires no `Content.onClose`. `grep` · `.claude/rules/ui.md` § Bottom sheets, first bullet · `git grep -nE '<BottomSheet\.Content|Content\.onClose' -- <files> ':!src/components/ui/sheet.tsx'`.
8. With a field focused, the field and the sheet's footer sit above the keyboard top, and the sheet closes on every path its features file names, the close proven by the screenshot. `device` · `.claude/rules/ui.md` § Bottom sheets, the keyboard-aware and `liftsAboveKeyboard` bullets · `.claude/skills/emulator-verify/SKILL.md`, the paragraph on `mqa bounds` keeping a closed sheet's nodes (`:183`).
9. A shared current-item slot with two writers is keyed by its owner or scoped to its screen, and a cache whose value is the same for every reader is keyed by id. `grep` · `.claude/rules/state.md` rule 5, `docs/adr/2026-09-15-account-lookup-keyed-by-id.md` §1 · `git grep -nE "from '(@/|\.\./)[^']*\.(store|state)'" -- <files> | grep -v ':import type '` lists each store or state a touched file imports by an alias or a `../` path. That covers a module's `store/`, the `src/store/` re-exports, a `src/components/ui` state, and a state kept in another folder, such as `src/modules/accounts/components/account_form/account_form.state.ts` or `src/modules/budget/screens/budget/budget.state.ts`. A store or state imported by a `./` path, from the importer's own folder or a folder below it, does not appear.
10. Every async write sets an error the UI renders. `grep` · `.claude/rules/review.md` class 1 · `git grep -nE -A2 'catch( \([^)]*\))? \{$|(^|[^A-Za-z0-9_.])void [A-Za-z_.]+\(' -- <files>` shows each catch with the two lines after it, so a comment-only body is visible, and each `void` call.
