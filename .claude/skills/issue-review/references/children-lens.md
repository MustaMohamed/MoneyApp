# Children lens (main thread)

Runs on the set of children after the group reviewers return, over their bodies and the code map. The main thread of a review session did not write the bodies, so it is fresh; no dispatch.

- **C1 Coverage both ways.** Every Building bullet of the parent lands in exactly one child; every child serves a Building bullet. For a task parent, its Acceptance lines stand in for Building.
- **C2 Edges across the set.** A dependency the code map shows between two children that no header names; an edge no code supports, which costs parallelism; every chain's first link stands alone, per [splitting.md](../../tickets/references/splitting.md).
- **C3 Overlap on the milestone.** Two open issues on the milestone touching the same module with no edge between them, whether or not they share a parent.
- **C4 The cut.** The parent's latest `Cut:` comment names the cut chosen at `/tickets`; the set still follows it. No comment: one `ask` delta, never a guess.

Deltas from this lens carry the same evidence rule as the charter and join the stop with the group reviewers' deltas.
