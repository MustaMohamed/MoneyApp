# Budget category detail

Route `/budget/[id]`, pushed from a category row on the `Budget` tab. Screen `src/modules/budget/screens/budget/category_detail/index.tsx`. The hero follows frame B1, S07 for over and S05 while loading (MA-330); Monthly result follows frame B1 (MA-320); the header, skeleton (S05), not found (S06) and load errors follow MA-321. This file carries only the state MA-130 needs; add the rest when a ticket reaches them.

## Reach it

- User path: the `Budget` tab, the `Categories` lens, then a category's budget row (`budget.md` § Outbound).
- Script: `$MQA open /budget/<category id>`, the id from `$MQA db "select category_id from budgets limit 1"`.
