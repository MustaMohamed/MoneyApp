## Risks
- MA-103 (#564) edits body :260; MA-105 the slots; MA-111 the From row. Step 6 touches only :349-367, so a rebase against any of them is a clean three-way merge; the second to merge keeps the first's lines.
- `ListGroup.Item` with no `ListGroup` parent is the shipped pattern at `account_fact_row.tsx:22`; if HeroUI 1.0.8's item reads a parent context for `variant`, the row falls back to its default styles, which is what the flat fact row wants.
- `Input` inside a row with `textAlign: 'right'` on Android may keep the caret left until the first character; a device-only look, not a test failure.
- `toHaveStyle({ minHeight })` on `ListGroup.Item` requires the style prop to reach the rendered pressable; `account_fact_row` has no test proving it, so if the matcher misses, assert on the `View` returned by `getByTestId` after `PressableFeedback` flattening, or drop to `toHaveProp('style', expect.arrayContaining(...))`.
- Amended after review: step 5 now swaps the skeleton's `DATE_ROW_HEIGHT` import in the same commit (typecheck was red between steps 5 and 7); step 7 draws D15's four key-and-value fact rows instead of three full-width bars, and its test is marked geometry-only with the emulator state as the proof.

## Self-assessment
Step 4 is the one I trust least. The `FormPickerRow` prop surface is preserved so the body's four callers do not change, but the right-hand column now has to hold a prefix, a truncating value and a suffix while the key keeps its full width, and `flexShrink`/`minWidth: 0` on the wrong node either lets a long account name push the chevron off or truncates the key instead of the value; the existing "long picker value" case at `transaction_form_body.test.tsx:113` catches the second failure but not the first, which only the D1 shot shows. The Note row (step 6) is the next uncertainty: the ticket calls it a fact row without saying how an input sits as a value, and I chose right-aligned text in the value face; if the canvas note field reads left, that is a one-line change to `textAlign` and the font class.
