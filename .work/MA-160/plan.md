Facts the steps lean on, cited once:

- A text in a fixed box draws with `allowFontScaling={false}` at a size the app scales, so the box and the text match by construction (`docs/adr/2026-09-27-transactions-search-tally.md` §7). `scaledTextStyle(size, 1)` is today's `fontSize` and `lineHeightFor` pair. ## Self-assessment
Step 4's hidden suffix is the one I am least sure about. The shared input must stay as it is, and it chooses between two input elements on whether `suffix` is truthy, so the only way to hide the label without remounting a focused field is to keep the element and empty it.
